# 이종대왕 달력 · PWA

교실 기록을 **달력·목록**으로 보고 관리하는 설치형 웹앱(PWA)입니다.
안드로이드 크롬에서 홈 화면에 추가하면 앱처럼 전체화면으로 열립니다.

👉 **열기**: https://wjoehasa-eng.github.io/leejong-calendar/

## 이 저장소에는 기록이 들어 있지 않습니다

이 저장소는 **앱 껍데기만** 담습니다. 달력 기록·수업 메모·자료 링크 같은 내용은
하나도 들어 있지 않고, 앞으로도 올리지 않습니다(`index.html`의 초기 데이터는 `events: []`).

- 사용자가 불러오는 기록은 오직 그 브라우저의 `localStorage`·`IndexedDB`에만 저장됩니다.
- 서버도 계정도 없습니다. 기록을 앱 개발자나 제3자에게 보내는 코드가 없습니다.
- 유일한 예외는 사용자가 **직접 지정한 본인 구글 시트**(Apps Script 웹 앱)로 보내는 백업·동기화이며,
  주소를 넣지 않으면 아무 데도 보내지 않습니다.
- 그래서 이 주소를 열어도 **빈 달력**이 보이고, 각자 자기 백업 파일을 불러와 씁니다.

## 쓰는 법

1. 휴대폰 크롬에서 위 주소를 엽니다.
2. 오른쪽 위 **⚙ 설정** → **JSON 불러오기** → 백업 파일(`이종대왕달력_YYYY-MM-DD.json`) 선택
   → **교체**(또는 **합치기**).
3. 브라우저 메뉴 → **홈 화면에 추가** 로 설치하면 오프라인에서도 열립니다.

기록 추가는 오른쪽 아래 **＋기록**, 편집·완료 표시는 항목을 눌러서 합니다.

## 백업 세 가지

| 방식 | 무엇을 | 어디에 | 쓰는 때 |
| --- | --- | --- | --- |
| **JSON 내보내기/불러오기** | 기록 전체 | 기기 파일 | 다른 기기로 옮기거나 손으로 보관할 때 |
| **타임머신 스냅샷** | 지금 상태를 이름 붙여 통째로, 최근 5개 | 이 브라우저(`localStorage`) | 연도 배치·큰 정리 전에 "한 번 저장" → 문제 있으면 그 시점으로 **복원** |
| **구글 시트 클라우드 동기화** | 기록 전체 | 사용자 본인 구글 시트 | 폰을 바꾸거나 브라우저 데이터를 지워도 남게, 시트에서 직접 열어 볼 때 |

### 타임머신 스냅샷
설정 → **지금 이 순간 상태 저장**. 목록에 저장 시각·기록 수·완료 수가 보이고 **복원**·**삭제**를 누를 수 있습니다.
복원 직후 3초 안에 **실행 취소**를 누르면 되돌릴 수 있습니다.

### 구글 시트 동기화 (한 번만 준비)
1. 구글 드라이브에서 새 스프레드시트를 만듭니다.
2. 그 시트에서 **확장 프로그램 → Apps Script** 를 열고, 이 저장소의
   [`apps-script/Code.gs`](apps-script/Code.gs) 를 그대로 붙여 넣고 저장합니다.
3. **배포 → 새 배포 → 웹 앱**, 실행: 나 / 액세스: **모든 사용자** → 배포 → URL 복사.
4. 앱 설정의 **구글 시트 클라우드 동기화** 칸에 그 URL(`…/exec`)을 넣고
   **시트로 저장 (백업)** 을 누릅니다.

시트에는 네 개의 탭이 생깁니다.

| 탭 | 내용 |
| --- | --- |
| `이벤트` | 기록 1개 = 1행 (id·날짜·제목·완료·태그·설명·링크·원본 JSON). 시트에서 직접 고쳐도 다음 불러오기에 반영됩니다. |
| `백업` | 통째로 저장한 원본 JSON 을 45,000자씩 나눠 담습니다. `이벤트` 탭이 지워져도 여기서 완전히 복구됩니다. |
| `메타` | 마지막 저장 시각·기록 수 |
| `사용법` | 위 내용 요약 |

시트로 보내는 요청은 `text/plain` POST(프리플라이트 없음)라서 앱과 Apps Script 사이에 CORS 문제가 생기지 않습니다.

### 실시간 자동 동기화 (거의 실시간)

시트 주소를 넣으면 설정의 **실시간 자동 동기화** 가 기본으로 켜집니다. 폰과 PC 에서 같은 주소를 넣어 두면
한쪽에서 고친 내용이 몇 초 안에 다른 쪽에 나타납니다.

| 동작 | 언제 | 어떻게 |
| --- | --- | --- |
| **자동 저장(push)** | 기록을 추가·수정·완료 토글·이동·삭제하거나, 드라이브 연결을 했을 때 | 마지막 편집에서 **1.5초** 뒤 시트로 올립니다(연달아 고치면 한 번만). 올리는 동안 화면은 그대로 쓸 수 있습니다. |
| **자동 확인(pull)** | 앱을 열 때, 탭/화면으로 돌아올 때(focus·visibilitychange), 다시 연결될 때 | 시트의 `savedAt` 이 이 기기의 마지막 동기화·편집보다 **1.5초 이상 새로울 때만** 그 내용으로 바꿉니다. 최대 6초에 한 번만 확인합니다. |

안전장치

- **시트가 비어 있으면(0개) 절대 기기 기록을 지우지 않습니다.** 시트의 시각 정보가 없을 때도 그냥 둡니다.
- 시트가 같거나 오래되었으면(시계 오차 1.5초 여유) 아무것도 하지 않습니다.
- 편집·설정 창이 열려 있는 동안에는 자동으로 화면을 바꾸지 않습니다.
- 오프라인이거나 저장에 실패하면 아래쪽에 `⚠️ 오프라인 · 기기에 저장됨` 처럼 조용히 알리고, 기록은 이 기기에 그대로 남깁니다. 연결이 돌아오면 최대 3번까지 다시 시도합니다.
- 저장과 확인은 서로 겹치지 않게 한 번에 하나씩만 실행합니다.
- 두 기기가 **동시에** 같은 기록을 고치면 나중에 저장한 쪽이 이깁니다(마지막 저장 우선). 한쪽에서 먼저 저장하고 다른 쪽에서 화면을 다시 열면 그 내용이 반영됩니다.

상태는 화면 왼쪽 아래의 작은 칩(`☁️ 동기화 중…` → `☁️ 자동 동기화됨`)과 설정의 안내 줄에 표시됩니다.
자동 동기화를 끄면 기록은 이 기기에만 저장되고, **시트로 저장 / 시트에서 불러오기** 로만 주고받습니다.

## 구글 드라이브 파일 연결 (상세 화면에서 한 번에)

기록을 **열기만 하면** 멘트 바로 아래에 **📁 드라이브 파일 붙이기** 줄이 있습니다. 편집 화면을 열 필요가 없습니다.

1. 드라이브에서 파일을 연 뒤 **공유 → 링크 복사** 합니다. (옆의 **드라이브 ↗** 로 바로 열 수 있습니다.)
2. 주소 칸을 눌러 **붙여넣기만** 하면 그 자리에서 붙습니다. (`[연결]` 을 눌러도 되고, 붙여넣기만 해도 됩니다.)
3. 이름은 주소를 보고 자동으로 정해집니다(`구글 프레젠테이션` / `구글 문서` / `구글 스프레드시트` / `구글 드라이브 파일`).
4. 붙는 즉시 저장되고 실시간 자동 동기화가 켜져 있으면 시트에도 올라갑니다. 잘못 붙였으면 토스트의 **실행 취소** 로 되돌립니다.

멘트·웹 링크·드라이브 자료는 상세 화면에서 **멘트 → 붙이기 줄 → 📎 드라이브 자료 → 🔗 링크** 순서로 한 묶음에 보입니다.

편집 화면의 **📁 구글 드라이브 파일 연결** 패널도 그대로 남아 있습니다(이름을 직접 적고 싶을 때).

| 주소 | 자동 이름 | 배지 |
| --- | --- | --- |
| `docs.google.com/presentation/…` | 구글 프레젠테이션 | SLIDE |
| `docs.google.com/document/…` | 구글 문서 | DOCS |
| `docs.google.com/spreadsheets/…` | 구글 스프레드시트 | SHEET |
| `drive.google.com/file/d/…` | 구글 드라이브 파일 | DRIVE |
| `drive.google.com/drive/folders/…` | 구글 드라이브 폴더 | DRIVE |

연결은 파일 본문이 아니라 **주소만** `links` 에 저장하므로 용량을 차지하지 않고, JSON 내보내기·불러오기와
구글 시트 동기화에도 그대로 살아남습니다. 기기에 직접 첨부한 파일 본문은 JSON 백업에 포함되지 않습니다.

## 기록을 지우는 방법

실수로 누적 기록이 날아가지 않도록 **일괄 초기화 버튼은 두지 않았습니다.**
기록을 줄이거나 되돌리는 길은 다음 세 가지뿐입니다.

| 방법 | 범위 | 되돌리기 |
| --- | --- | --- |
| 기록 상세의 **삭제** | 그 기록 1건 | 실행 직후 **실행 취소** |
| **타임머신 스냅샷 복원** | 저장해 둔 시점 전체 | 복원 직후 3초 안에 **실행 취소** |
| **JSON 불러오기 → 통째로 바꾸기** | 불러온 파일 전체 | 실행 전 스냅샷을 먼저 저장해 두세요 |

> 완료 표시는 기록마다 하나씩 직접 끄면 됩니다. 구글 드라이브 파일 연결은 주소만 담은 자료라서
> 기록을 지워도 드라이브의 원본 파일은 그대로입니다.

## 화면

| 보기 | 내용 |
| --- | --- |
| **월간** | 달력 격자에 날짜별 기록 알약(pill). 누르면 상세, 완료는 ✓ 로 표시 |
| **목록** | 이 달 기록을 카드 목록으로. 정렬(오래된·최신), 제목·설명·태그 검색 |
| **설정** | 기록 수·완료 수·자료 수, JSON 내보내기/불러오기, 타임머신 스냅샷, 구글 시트 동기화, 연도 배치 도우미 |

라이트/다크 모드를 자동으로 따르고, 휴대폰·태블릿·데스크톱 모두에서 쓸 수 있습니다.

## 구조

```
index.html            화면 (CSS·앱 로직 포함, 외부 라이브러리·CDN 없음)
manifest.json         설치형 앱 정보 (이름·아이콘·테마)
sw.js                 서비스 워커 — 껍데기 캐시, 오프라인 실행
icon-192.png · icon-512.png
.nojekyll             GitHub Pages 가 파일을 그대로 서빙하도록
apps-script/Code.gs   구글 시트 백업용 Apps Script (사용자가 자기 시트에 붙여 넣음)
```

## 개인정보

- 저장소·페이지에 개인 기록, 학급 기록, 학생 정보, 자료 링크가 없습니다.
- 쿠키·분석 도구·외부 스크립트를 쓰지 않습니다.
- 브라우저 데이터를 지우면 기기에 저장된 기록도 함께 지워지므로, JSON 내보내기나 구글 시트 백업을 권합니다.
